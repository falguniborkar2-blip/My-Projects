# University Projects - Falguni Borkar

Course projects from my MSc in Machine Learning and Data Mining at Masaryk University, Brno.

| Project | What it is | Tools |
|---|---|---|
| [Human Activity Recognition](human-activity-recognition/) | Classifying 6 activities from smartphone sensor data, comparing 5 models with statistical tests | Python, scikit-learn, pandas |
| [Information Retrieval](information-retrieval/) | Search systems for the Cranfield and CQADupStack collections, evaluated with MAP | Python, SentenceTransformers, PyTorch |
| [Flask Service Deployment](flask-service-deployment/) | One small web service deployed three ways: uWSGI + nginx on Linux, a Docker image, and a VM on OpenStack with Terraform | Flask, uWSGI, nginx, Docker, Terraform, OpenStack |

My main project is **[OpsLens](https://github.com/falguniborkar2-blip/opslens)**, a RAG + MCP assistant for Linux and Kubernetes.
